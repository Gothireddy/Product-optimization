Steam Cracking Optimization for Petrochemical Products
Overview

This project implements a Python-based model to optimize the steam cracking process of hydrocarbon fractions, including heavy, light, and naphtha cuts, to maximize the yield of key petrochemical products: butadiene, propene, and ethylene. The simulation accounts for different cracking modes for each feedstock and applies linear algebra and combinatorial search techniques to determine the optimal cracking setup.

Features

Models steam cracking for multiple hydrocarbon fractions.

Optimizes product yields based on user-defined targets.

Calculates the total cracking consumption and resulting product output per 1 barrel of feedstock.

Supports different cracking efficiencies and modes.

Technologies

Python 3.x

Libraries: numpy, itertools
